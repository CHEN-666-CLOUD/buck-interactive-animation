Boost 升压电路全支路电流动画

Vin = 5 V · L = 470 μH · C = 470 μF · R = 50 Ω · D1 = 1N5822

当前：S 导通（ON）Vin 给 L 储能；D 截止；输出电容 C 独立给负载供电。
iVin / iLON：Vin → L → S，iL 上升。
iSON：iS = iL，经 S 回到 GND。
iDON：iD = 0，二极管截止。
iLoad始终从 Vout → R → GND。
iCON：C 放电，给负载供电。
当前工况OFF 整段近似 iL > iLoad，所以 C 整段充电。

说明：OFF 时电容充放电的严格判断仍是 iC = iL - iLoad。本动画按当前仿真工况显示：iL ≈ 0.348–0.572 A，iLoad ≈ 9/50 = 0.18 A，因此 OFF 整段近似为电容充电。
